## SYNC는

차량 신호와 운전자의 상황을 **같은 위상으로 맞추는** 차량용 앱을 만드는 팀입니다.
스마트폰을 차에 옮겨 놓은 앱이 아니라, 차 안에서만 의미가 있는 기능을 만듭니다.

## 만드는 방식

| | |
| 원칙 | 내용 |
|---|---|
|---|---|
| **차량 특화** | 차량 상태(Vehicle State)와 내비게이션 이벤트를 실시간으로 받아 주행·정차 맥락에 맞게 반응합니다. |
| **주행 안전 우선** | 주행 중에는 짧고 큰 정보만, 정차 중에는 자세한 정보를 보여 줍니다. 주행 규제(UX Restrictions)를 설계 단계부터 반영합니다. |
| **실제로 동작하는 코드** | 목업 대신 SDK 실측과 로그로 검증합니다. 문서와 실제 동작이 다르면 실제 동작을 기준으로 삼습니다. |
